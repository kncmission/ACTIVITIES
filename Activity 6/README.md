# Activity 6: AI-Assisted Website Development

## Overview
This activity introduced me to website development using AI-powered tools, particularly Replit, and allowed me to experience how AI can simplify the coding and development process.

## Key Concepts and Skills Gained
I learned how to create a website with the assistance of AI. The activity introduced me to how AI can simplify the website development process by helping generate code, organize website elements, and bring ideas into an actual working website.

## Challenges Encountered and Solutions
One challenge I encountered was my unfamiliarity with Replit and its different features. Although I had some previous experience with manually writing code, I was not yet familiar with the platform itself. Through proper guidance and exploration, I was eventually able to understand how it worked and successfully develop my website.

## Future Applications
I can apply what I learned if I decide to create my own website in the future, whether for personal, academic, or professional purposes. This activity also showed me how AI can make technical tasks more accessible, even for those who may not have extensive programming experience.
