# Activity 4: Exploring Google Sheets

## Overview
This activity introduced me to the different functions and applications of Google Sheets and how it can be used for organizing information and managing data.

## Key Concepts and Skills Gained
I learned about the different functions, processes, and applications available in Google Sheets. The activity helped me become more familiar with how spreadsheets can be used to organize information, perform calculations, and manage data more efficiently.

One challenge I encountered was my limited familiarity with the different formulas and functions in Google Sheets. I initially had difficulty understanding how to use them correctly, but through practice and familiarization, I was able to understand their basic applications better.

## Future Applications
I can apply these skills in the future, particularly when creating schedules, organizing information, and managing finances. These skills may also be useful in my nursing career when handling patient-related data, organizing records, and preparing reports.
